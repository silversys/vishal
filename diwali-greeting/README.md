# 🪔 Shubh Deepavali — Bansal Family Greeting

A personal Diwali greeting from **Muskan, Vishal, Parv & Vrishti Bansal**:
a 29-second WhatsApp reel, a still greeting card, and ready-to-paste WhatsApp messages.

| File | What it is |
|---|---|
| `output/shubh-deepavali-reel.mp4` | 29 s vertical reel (1080×1920, 30 fps, H.264 + AAC, ~10 MB) for WhatsApp Status, chats or Instagram Reels |
| `output/shubh-deepavali-thumbnail.png` | The reel's first frame, which is the title screen WhatsApp uses as the video thumbnail |
| `output/shubh-deepavali-card.png` | Still greeting card (1080×1920) to send as a photo |
| `WHATSAPP-MESSAGES.md` | 6 messages: Hindi (long and short), English, Hinglish, Status caption, and one for elders |

## Reel storyboard

| Time | Scene |
|---|---|
| 0–2.2 s | **Title screen** (the first frame and thumbnail): ॐ, शुभ दीपावली, Happy Diwali and the family's names, with fireworks already bursting |
| 2.2–6.8 s | **॥ श्री गणेशाय नमः ॥**: glowing ॐ inside a turning golden mandala |
| 6.8–12.8 s | **Shri Ram, Mata Sita, Lakshman ji, with Pawanputra Hanuman**: Ram's bow and arrow, Hanuman's gada, Ayodhya palace with a saffron flag, rows of lamps along the rooftops, falling flower petals |
| 12.8–17.8 s | **Maa Laxmi**: a lotus opens, "श्री" rises from it, gold coins fall |
| 17.8–22.8 s | **Gifts, sweets, lights and crackers**: gift boxes bounce in and open, a laddoo thali, anaar fountains, fireworks |
| 22.8–29.2 s | **शुभ दीपावली / Happy Diwali** over a rangoli, with fireworks and the family's names |

Every scene has a marigold toran, floating sky lanterns and a row of diyas. The soundtrack is generated by code and has no copyrighted music: tanpura drone, bansuri-style melody, dholak (keherwa), temple bells, coin chimes, and cracker sounds timed to each firework.

## Change the names and rebuild

Requirements: Node with Playwright, Python 3 with numpy, and ffmpeg.

```bash
node make-reel.js output \
  --from "Muskan, Vishal, Parv & Vrishti" \
  --fromhi "मुस्कान, विशाल, पर्व एवं वृष्टि बंसल" \
  --family "Bansal Family"
```

To watch the animation live, open `reel.html` in a browser. Names can also be passed in the URL: `reel.html?from=...&fromhi=...&family=...`.

Fonts are from Google Fonts (SIL Open Font License): Rozha One, Tiro Devanagari Hindi, Kalam, Yatra One and Cinzel Decorative.
