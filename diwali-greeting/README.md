# 🪔 Shubh Deepavali — Bansal Family Greeting

A personal Diwali greeting from **Muskan, Vishal, Parv & Vrishti Bansal**:
a 27-second WhatsApp reel, a still greeting card, and ready-to-paste WhatsApp messages.

| File | What it is |
|---|---|
| `output/shubh-deepavali-reel.mp4` | 27 s vertical reel (1080×1920, 30 fps, H.264 + AAC, ~9 MB) for WhatsApp Status, chats or Instagram Reels |
| `output/shubh-deepavali-card.png` | Still greeting card (1080×1920) to send as a photo |
| `WHATSAPP-MESSAGES.md` | 6 messages: Hindi (long and short), English, Hinglish, Status caption, and one for elders |

## Reel storyboard

| Time | Scene |
|---|---|
| 0–4.6 s | **॥ श्री गणेशाय नमः ॥**: glowing ॐ inside a turning golden mandala while the diyas light one by one |
| 4.6–10.6 s | **Shri Ram, Mata Sita, Lakshman ji, with Pawanputra Hanuman**: Ram's bow and arrow, Hanuman's gada, Ayodhya palace with a saffron flag, rows of lamps along the rooftops, falling flower petals |
| 10.6–15.6 s | **Maa Laxmi**: a lotus opens, "श्री" rises from it, gold coins fall |
| 15.6–20.6 s | **Gifts, sweets, lights and crackers**: gift boxes bounce in and open, a laddoo thali, anaar fountains, fireworks |
| 20.6–27 s | **शुभ दीपावली / Happy Diwali** over a rangoli, with fireworks and the family's names |

Every scene has a marigold toran, floating sky lanterns and a row of diyas. The soundtrack is generated by code and has no copyrighted music: tanpura drone, bansuri-style melody, dholak (keherwa), temple bells, coin chimes, and cracker sounds timed to each firework.

## Change the names and rebuild

Requirements: Node with Playwright, Python 3 with numpy, and ffmpeg.

```bash
node make-reel.js output \
  --from "Muskan, Vishal, Parv & Vrishti" \
  --fromhi "मुस्कान, विशाल, पर्व एवं वृष्टि बंसल" \
  --family "Bansal Family"
```

To watch the animation live, open `reel.html` in a browser. Names can also be passed in the URL: `reel.html?from=...&fromhi=...&family=...`.

Fonts are from Google Fonts (SIL Open Font License): Rozha One, Tiro Devanagari Hindi, Kalam, Yatra One and Cinzel Decorative.
